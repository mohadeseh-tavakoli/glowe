# GLOWÉ Beauty Boutique

قالب استاتیک فارسی و راست‌چین فروشگاه چندبرندی محصولات آرایشی و مراقبت پوست.

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## انتشار در GitHub Pages
1. تمام محتویات این پوشه را در ریشه یک repository قرار دهید.
2. وارد Settings → Pages شوید.
3. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و Save کنید.

## نکته
این پروژه نسخه نمایشی فرانت‌اند است. سبد خرید، جستجو و علاقه‌مندی‌ها در مرورگر به‌صورت نمایشی کار می‌کنند و هنوز به درگاه پرداخت، پنل مدیریت یا پایگاه داده متصل نیستند.
تصاویر محصولات COSRX، Beauty of Joseon و Charlotte Tilbury از منابع خارجی بارگذاری می‌شوند و برای نمایش آن‌ها اتصال اینترنت لازم است.


## محصولات اضافه‌شده
۱۳ محصول جدید از تصاویر ارسالی در مسیر assets/products قرار گرفته‌اند. برای هر محصول صفحه جزئیات اختصاصی با آدرس product.html?product=... ساخته می‌شود. قیمت‌هایی که از طرف کاربر اعلام نشده‌اند به‌صورت «استعلام قیمت» نمایش داده می‌شوند.
